# Git Version Control DevOps Project

## Project Overview
This project demonstrates Git version control best practices
using Git and GitHub.

## Objectives
- Understand Git version control.
- Practise branching strategies.
- Implement Pull Requests.
- Understand merging and rebasing.
- Manage project versions using Git tags.
- Document Git workflows.

## Tools Used
- Git
- GitHub
- Linux
- Visual Studio Code

## Branching Strategy

| Branch | Purpose |
|---|---|
| main | Stable production branch |
| dev | Development branch |
| feature/* | Feature development |

## Git Workflow
1. Create a feature branch from dev.
2. Make changes to project files.
3. Stage and commit changes.
4. Push the feature branch to GitHub.
5. Create a Pull Request.
6. Merge into dev.
7. Merge dev into main.
